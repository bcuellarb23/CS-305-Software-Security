# CS-305-Software-Security

Artemis Financial is a consulting company that develops individual financial plans for its customers. The financial plans include savings, retirement, investments, and insurance. Artemis Financial has a public web interface and wants to use the most current and effective software security, and they want us to protect their client data and financial information. 

I have implemented good practices to secure their software by implementing the most secure Algorithm cipher released using TLS 1.3. This cipher uses a bulk encryption cipher, AES, and a key size of 256bits, and a hash function, SHA-384, that better handles future quantum-assisted analytical threats. Securing Artemis Financial software is fundamental for their company because it keeps their customers data safe, if any data is liked customer will lost their trust in the services. 

The most challenging part was learning and understanding the different concepts of securing software. Getting fluent in algorithms and secure best practices is challenging because it requires extensive research to know the latest and most secure practices used in the industry. 

Implementing secure best practices is important when creating software. In future implementations, I will follow the basic best practices, which are secure session lifecycle, credential protection, checking untrusted user input, preventing injection attacks, Data protection by encryption, validation of files, and secure error handling. 

Good examples of work will be documentation of the work done. Documents containing checks and code refactoring done will be the best example to show to a company so they can understand what was implemented and why it was done in that way.
